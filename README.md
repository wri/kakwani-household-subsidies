# Kakwani analysis of household expenditures and subsidies

## Overview

This code describes analyses of household expenditures and subsidies associated with the WRI Insights article "Breaking the Fossil Fuel Subsidy Cycle Can Build Resilience to the Next Energy Crisis", published 2026.

The analysis is performed for three geographies.

## Data Availability and Provenance Statements

Source data for these analysis is as follows:

### Ethiopia

**Ethiopia Household Consumption Expenditure Survey 2015-2016**: https://ess.gov.et/download/14023/ 


### India

**India Household Consumption Expenditure Survey**: https://microdata.gov.in/NADA/index.php/catalog/237/study-description

- Microdata requires a login, therefore should be obtained independently
- This analysis uses:
	- Level 05
	- Level 08
	- Level 09
	- Level 15

### Mexico

The data is collected from public sources (National Institute of Statistics and Information, INEGI; Ministry of Energy, Sener; Newspapers articles, among others).
